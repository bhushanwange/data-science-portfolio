# 🚀 Data Science Portfolio (Phase-1)

Welcome to my portfolio repository showcasing machine learning models, predictive APIs, classification pipelines, and business intelligence dashboards.

---

## 📂 Project Showcase

### 1. Linear Regression: California House Price Prediction (`/Linear_Regression`)
* **Description**: A machine learning regression model built with Python and `scikit-learn` that predicts house prices based on demographic and geographic features. Deployed as a web prediction API using Flask.
* **Tech Stack**: Python, pandas, scikit-learn, joblib, Flask, REST API.
* **Key Files**: 
  * `train_model.py`: Model training script.
  * `house_price_model.pkl`: Saved serialized regression model.
  * `app.py`: Flask prediction API endpoint (`/predict`).
  * `requirements.txt`: Project dependencies.

### 2. Logistic Regression: Classification Pipeline (`/Logistic_Regression`)
* **Description**: A classification model built to evaluate binary outcomes featuring data standardization, logistic regression, and evaluation metrics (ROC-AUC).
* **Tech Stack**: Python, scikit-learn, pandas, matplotlib.
* **Key Files**: Classification script and supporting files.

### 3. Business Intelligence Dashboard (`/Dashboard`)
* **Description**: An interactive analytics dashboard visualizing key sales metrics, regional distributions, and transactional insights.
* **Tech Stack**: Power BI Desktop, CSV data processing.
* **Key Files**: Power BI dashboard file (`.pbix`) and underlying sales dataset.
